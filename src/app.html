The relay prints this when it starts. Send it to your phone and paste it here.
  1. On a computer that stays on at home, install Python and Tailscale, and sign in to Tailscale.
  2. Install Tailscale on this iPhone with the same account and leave it on.
  3. On the computer, run tailscale serve --bg 7788 once, then start the relay.
  4. Paste the Lights link it prints above.

Full guide: relay setup. Phosphor OS uses the same relay and link.

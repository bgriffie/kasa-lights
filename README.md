# Kasa Lights

A PHOSPHOR home-screen web app for switching and dimming Kasa bulbs. It talks to the lights relay
(`bridge/kasa_bridge.py` in [phosphor-os](https://github.com/bgriffie/phosphor-os/tree/main/bridge)) over Tailscale.

Live: https://bgriffie.github.io/kasa-lights/

Source lives in `src/`; run `python3 build.py` to rebuild `index.html`.
